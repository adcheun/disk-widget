# DiskWidget v1.1.0

本版本新增 macOS 原生应用图标、Liquid Glass 桌面悬浮卡片升级以及原生 WidgetKit 桌面小组件扩展（`DiskWidgetWidget.appex`），面向 Apple Silicon macOS 13+（原生系统小组件需 macOS 14+）。

## 主要更新

- **全新 macOS 原生应用图标**：1024×1024 Squircle 黑曜石毛玻璃图标，集成存储仪表环与铝金属外置硬盘硬件造型。
- **原生 WidgetKit 系统小组件**：支持「外置磁盘总览」（小 / 中 / 大尺寸）与「指定外置磁盘」桌面及通知中心小组件，支持实时同步、一键切换 `已用% / 剩余%` 与安全推出。
- **三种单击桌面效果 & 实时调节**：提供「原生毛玻璃」「深色面板」「通透玻璃」三套统一效果，所有磁盘一致联动；“玻璃背景”滑块支持实时预览。
- **卡片信息与按钮优化**：状态等宽容量进度条、文件系统格式徽章，卡片内保留独立快捷推出按钮；右键菜单区分「安全推出」「完全推出（断电移除）」与「强制推出…」。
- **桌面空间与设置稳定性修复**：卡片严格留在普通桌面空间（`.stationary + .fullScreenNone`），切换空间零延迟贴合壁纸，进入调度中心自动退避隐藏；修复设置页标签文本重叠与打开/关闭设置跨全屏空间跳转问题。

## 安装

解压 `DiskWidget-1.1.0-macOS-arm64.zip`，将 `DiskWidget.app` 拖入「应用程序」文件夹后启动即可。

校验文件：`SHA256SUMS-1.1.0.txt`。
