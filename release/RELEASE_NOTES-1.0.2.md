# DiskWidget v1.0.2

本版本基于 Gemini 优化后的最新版源码构建，面向 Apple Silicon macOS 13+。

## 主要更新

- 改进磁盘卡片的原生 macOS 视觉效果和交互反馈。
- 识别只读卷、安装镜像和 Time Machine 备份盘并使用对应图标。
- 增强多显示器位置保持、新设备加入和卡片重排逻辑。
- 进入调度中心时隐藏卡片，退出后恢复。
- 增加窗口行为和布局回归测试。
- 保持本地运行，不联网、不收集数据。

## 安装

解压 `DiskWidget-1.0.2-macOS-arm64.zip`，将 `DiskWidget.app` 拖入“应用程序”。如需开机运行，在系统设置的“登录项”中添加它。

校验文件：`SHA256SUMS-1.0.2.txt`。
